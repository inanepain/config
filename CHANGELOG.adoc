= 0.5.0-dev (2026 Xxx xx)
:revnumber: 0.5.0
:revdate: 2026-xx-xx
:revremark: -dev
:version-label: Unconfirmed

* ConfigAwareAttribute:
** `$globalConfig`: deprecated and will be removed in the next version.
** `$configKey` (bool|string):
*** expands on the *global* or *class-string* configuration options provided by `$globalConfig` (bool).
*** allows for the config key to be specifically specified by adding support for `string` values.
*** in addition to php's array key restrictions,
* `ConfigManager`:
** *new* class that handles loading the correct config based on the `ConfigAwareAttribute` options.
** *new* `ConfigNotFoundException` thrown when the *key* is invalid.
